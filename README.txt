# Roastery-Shopper

## Descripción
Es una página donde podés comprar bolsas de café y agregué el footer.

## Qué hace el JavaScript
Carga los productos y las categorías con arrays. Permite filtrar los productos por categoría, agregarlos al carrito, modificar las cantidades y vaciar el carrito. El carrito se guarda en localStorage y permance al recargar la página.

## Cómo probarlo
1. Abrir `index.html` en el navegador.
2. Ir a `Catalog` y cambiar el filtro de categoría.
3. Hacer clic en `Add` para agregar un producto al carrito.
4. Hacer clic en `Cart` para abrir el carrito y usar los botones `+` y `−` para cambiar la cantidad, o `Clear all` para vaciar el carrito.
5. Agregar un producto y recargar la página para comprobar que sigue guardado.
